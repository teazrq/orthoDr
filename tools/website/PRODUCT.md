# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Provide the orthoDr R package's GitHub Pages documentation. Users should be
able to install the package, choose a modeling workflow, reproduce an example,
and find function arguments and release notes.

## Capabilities and Constraints

The source package supports regression, censored survival outcomes,
personalized dose finding, and general orthogonality constrained optimization.
Tutorials describe the revised development version 2.0.0 and reuse the checked
examples in `inst/examples`. Documentation must distinguish this version from
the CRAN release.

## Brand Commitments

Use pkgdown with the Bootstrap 5 Cosmo theme and familiar package
documentation navigation. The repository is `teazrq/orthoDr`; the publication
address is https://teazrq.github.io/orthoDr/. Keep this planning document in
the tools directory so it is not published as a package documentation page.
